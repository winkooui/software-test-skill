> AI 驱动的软件测试全生命周期 Skill 套件 —— 从 PRD 到测试用例到测试报告，一站式自动化。

## ✨ 核心能力

本套件包含两大模块，覆盖软件测试的核心工作流：

### 📋 模块一：测试用例生成（6 阶段）

从 **PRD/需求文档** 到 **结构化 Excel 测试用例** 的端到端生成：

| 阶段 | 名称 | 核心动作 |
|------|------|----------|
| 0 | 测试左移 | 可测试性评估（22 项检查点，0-10 分），< 6 分反馈需求方 |
| 1 | 需求获取 | 提取产品目标、功能列表、业务流程、非功能需求、已知约束 |
| 2 | 产品分析 | 架构分析 + 功能树 + **变更影响五层追溯** + **相近度计算** + 环境策略 |
| 3 | 交互确认 | 展示相近度报表，11 个反向问题确认回归范围 |
| 4 | 用例生成 | 标准业务用例 + 回归分层 + 环境分层 + **用户视角三类** + Prod 门禁集 |
| 5 | 8 层审查 | 功能覆盖率 ≥95%、类型覆盖 ≥3、回归覆盖（高100%/中≥70%/低≥50%）等 |
| 6 | 交付 | 11 Sheet Excel + 相近度报表 + 回归确认单 + Prod 门禁单 |

**核心创新**：
- 🔢 **相近度模型**：代码×0.30 + 数据×0.25 + API×0.20 + 业务×0.15 + UI×0.10，精准锁定回归范围
- 👤 **用户视角三类**：新手探索式 / 非预期路径 / 直觉偏差，覆盖真实用户行为
- 🎯 **9 种测试类型**：F(功能)/I(接口)/P(性能)/S(安全)/C(兼容)/U(UX)/E(异常)/N(负面)/R(回归)

### 📊 模块二：测试报告生成（6 步骤）

从 **测试执行追踪数据** 到 **可视化 Excel 报告**：

| 步骤 | 名称 | 核心动作 |
|------|------|----------|
| 1 | 接收解析 | pandas 自动识别列结构，提取元数据 |
| 2 | 数据清洗 | 完整性/状态标准化/合理性校验，输出数据质量报告 |
| 3 | 多维统计 | 整体/优先级/模块/类型/覆盖率/缺陷/效率 7 维度 |
| 4 | 图表生成 | 10 种图表（饼图/柱状图/雷达图/趋势图等），无 matplotlib 降级 ASCII art |
| 5 | 风险评估 | 10 条自动风险规则 + 6 因子上线就绪度评分（A/B/C/D） |
| 6 | 交付 | 10 Sheet Excel 含 KPI 仪表盘 + 图表 + 条件格式 |

## 🏗️ 架构设计

```
software-test-skill/
├── SKILL.md                 # 入口文件，双模块能力速览
├── core/                    # 核心逻辑层（平台无关）
│   ├── prompts/             # Prompt 定义（去平台化）
│   ├── workflows/           # 工作流定义（6阶段+6步骤）
│   ├── frameworks/          # 5 个分析框架
│   ├── schemas/             # 3 个数据 Schema（YAML + JSON）
│   ├── templates/           # 3 个输出模板（Excel + 图表 + 工具映射）
│   └── capability-contract.yaml  # 平台无关能力契约（14+4 种能力）
├── adapters/                # 4 平台适配器
│   ├── solo/
│   ├── claude-code/
│   ├── trae-qoder/
│   └── codex/
├── scripts/                 # Python 依赖
├── examples/                # 示例输入输出（预留）
└── tests/                   # 自测用例（预留）
```

**设计理念**：核心逻辑与平台解耦，通过适配层支持多 AI 编程助手平台。

## 🚀 快速开始

### 安装

```bash
# 将 skill 添加到你的 AI 编程助手
# 不同平台的安装方式参考 adapters/ 下的对应配置
```

### 依赖

```bash
pip install -r scripts/requirements.txt
# 核心依赖: openpyxl>=3.1.0, pandas>=2.0.0, matplotlib>=3.8.0
```

### 使用示例

**生成测试用例**：向 AI 助手提供你的 PRD 文档，触发测试用例生成工作流：

```
请根据以下 PRD 生成测试用例：
[粘贴你的需求文档]
```

**生成测试报告**：提供测试执行追踪数据（CSV/JSON/文本），触发报告生成：

```
请根据以下测试执行记录生成测试报告：
[粘贴测试追踪数据]
```

## 📐 关键数据模型

### 相近度模型

```
综合相近度 = 代码×0.30 + 数据×0.25 + API×0.20 + 业务×0.15 + UI×0.10

等级划分：≥4.0 高 | 2.0-3.9 中 | 1.0-1.9 低 | 0.1-0.9 微 | 0 无关
```

### 上线就绪度评分

```
基础 100 分
- P0 未通过: -3/个
- 致命缺陷: -10/个
- 严重缺陷: -3/个
+ 回归全通过: +5
+ 灰度方案: +3
+ 回滚方案: +3
- 历史事故: -5

评级: A≥90 | B≥75 | C≥60 | D<60
```
