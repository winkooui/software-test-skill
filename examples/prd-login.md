# 示例 PRD：账号登录与安全校验

## 背景

为提升企业用户登录体验，新增统一账号登录页，支持账号密码登录、错误次数锁定、登录成功后的跳转恢复，并为后续接入 MFA 预留接口。

## 目标

- 用户可以使用手机号或邮箱 + 密码登录。
- 登录成功后跳转到用户原本访问的页面。
- 连续 5 次密码错误后锁定账号 15 分钟。
- 登录接口需要输出可追踪的错误码，便于前端展示和客服排查。

## 功能范围

### 账号密码登录

- 支持手机号或邮箱作为账号。
- 密码长度为 8-32 位。
- 登录成功后创建会话并写入安全审计日志。
- 登录失败时不暴露账号是否存在。

### 错误次数锁定

- 同一账号连续 5 次密码错误后锁定。
- 锁定期间继续登录时返回 `ACCOUNT_LOCKED`。
- 锁定时间到期后自动解锁。
- 成功登录后清零错误次数。

### 跳转恢复

- 未登录用户访问受保护页面时，系统记录 `redirect_url`。
- 登录成功后跳回原页面。
- 非本站 URL 不允许作为跳转目标。

## 非功能要求

- 登录接口 P95 响应时间不超过 300ms。
- 密码、会话 token、错误详情不得写入明文日志。
- 登录按钮需要防重复提交。
- 移动端 375px 宽度下表单可正常使用。

## 依赖与约束

- 依赖用户中心接口 `/api/users/authenticate`。
- 依赖 Redis 记录错误次数和锁定状态。
- 依赖审计日志服务记录登录结果。
- 暂不包含 MFA 验证流程，仅预留接口字段。

## 已知风险

- Redis 故障时错误次数可能无法记录。
- 外部系统可能传入非法 `redirect_url`。
- 历史账号中存在手机号和邮箱重复绑定情况。
